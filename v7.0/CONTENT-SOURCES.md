## 이미지와 사례의 구분

고객사 로고는 제공된 원본 공개 고객 목록에 있던 자료를 사용했습니다. 고객별 최신 도입 범위, 현재 계약 상태, SOC 사용 여부와 공개 권한을 새로 확인한 것은 아닙니다. 고객사 전체가 모든 기능을 사용하는 것처럼 표시하지 않았습니다.

아이네트호스팅 고객 의견은 원본 홈페이지에 있는 문장과 기명 정보를 사용했습니다. 새로운 추천사나 성능 수치는 만들지 않았습니다.

제품 스크린샷은 원본 홈페이지의 공개 이미지를 사용했습니다. 홈페이지 v7 UI와 제품 콘솔 UI를 구분했습니다. 실제 제품 화면에는 기존 공개 화면임을 표시했습니다.

메인의 공격 증거·AI 분석 예시·보고서 구성은 새로 작성한 설명용 HTML입니다. 실제 운영 화면, 실시간 데이터 또는 시험 통과 결과가 아닙니다. 마크다운 보고서도 양식·구성 예시입니다.

1. 현재 제공하는 AI 분석 기능과 실제 자동화·승인 연계 범위.

3. SaaS·구축형의 지원 차이와 외부 AI 데이터 처리 조건.
4. 인증·지정 적용 제품·버전·유효기간·현재 상태 및 증서.
5. 고객 로고·고객 의견·제품 화면의 공개 가능 여부.
6. 기존 온라인 상담 양식의 제품 중심 질문을 v7 통합 도입 방식으로 변경할지 여부.
