# PLURA 홈페이지 변경 이력

## v7.0 — 2026-09-14

이번 버전은 홈페이지의 메이저 개편입니다. 제품 콘솔의 버전 변경은 아닙니다.

### 포지셔닝

개별 제품 목록에서 AI 기반 사이버보안 플랫폼 PLURA-XDR 중심으로 전환했습니다. PLURA-XDR + SOC를 대표 통합 제안으로 배치했습니다. 원천 데이터·공격 맥락·정책 기반 대응·관제 운영을 핵심 설명 흐름으로 정리했습니다.

### 정보 구조

상단 메뉴를 PLURA-XDR / AI 보안관제 / 위협 대응 / 고객·자료 / 도입 안내로 재구성했습니다. 핵심 콘텐츠 19개와 기능·기술 상세 10개를 작성했습니다. 기존 주요 URL은 유지하거나 호환 이동 파일로 연결했습니다.

### 디자인·동작

다크 네이비와 민트의 반응형 디자인, 통합 메뉴, 설명용 사건 탭, 시나리오 탭, 자료실 검색·필터, FAQ, 제품 이미지 확대, 도입 상담 초안을 구현했습니다. 공통 리소스는 res/v7/로 분리했습니다. 폰트 파일이나 외부 프런트엔드 라이브러리를 포함하지 않았습니다.

### 제공 범위

한국어 페이지를 작성했습니다. 영문·일본어는 기존 공식 페이지로 연결합니다. 기존 공식 온라인 상담과 이메일 앱으로 연결하며, 신규 접수 서버나 실제 서비스 배포는 포함하지 않습니다. 샘플 UI는 실제 제품 화면과 구분해 표시합니다.
