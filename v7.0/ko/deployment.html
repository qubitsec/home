DEPLOYMENT OPTIONS

운영 환경에 맞는 배포 구성을 검토합니다.

클라우드 SaaS

클라우드 기반 서비스 도입을 검토합니다. 보호 자산의 설치·수집 구성, 네트워크 연결과 데이터 처리 조건을 확인합니다.

구축형 협의

내부 환경과 데이터 통제 요구가 있는 경우 구축형 적용 가능 여부, 인프라·유지보수·서비스 제공 범위를 별도 협의합니다.

두 방식의 모든 기능·비용·운영 조건이 같다는 의미는 아닙니다. 망 분리·폐쇄망·외부 연결 제한 등은 개별 환경에서 지원 가능 여부를 먼저 확인합니다.

DATA LIFECYCLE

보안 데이터의 처리 단계를 구분합니다.

처리 단계확인할 사항
생성과 수집감사 정책, 웹 로그 구성, 수집 대상과 제외 항목
전송과 접근연결 경로, 암호화와 인증, 관리 접근 권한 및 접근 이력
분석과 활용분석 기능별 사용 항목, 관제 인력 접근 범위, 자료 제공 방식
보관과 조회원문·분석 결과·포렌식 자료별 보관 조건과 조회 권한
계약 종료·삭제보관 종료·계약 종료 시 데이터 제공·삭제 절차와 확인 방법

이 표는 도입 시 확인할 항목입니다. 특정 인증·보관기간·저장 지역·암호화 방식·완전 삭제 증명을 모든 구성에서 제공한다고 일괄 확정하지 않습니다.
