7대 필러 공식 원문 (새 탭)

PLURA-XDR / FOUR CONNECTED ROLES

가시성을 만들고,
분석을 대응으로 연결합니다.

01 / NETWORK & ENVIRONMENT

네트워크·환경의 가시성

WAF · 네트워크/보안 장비 로그

웹 요청·응답의 헤더·본문과 지원 장비·호스트의 연결 로그를 수집·분석합니다. 공격 요청과 접근 흐름을 연결하고 정책에 따른 웹 공격 차단에 활용합니다.

수집·분석과 웹 방어 범위의 지원이며, 전사 네트워크 세분화나 모든 통신의 제어를 자동 대체하지 않습니다.

웹 보호 기능

02 / DEVICE

서버·PC 행위와 보안 상태

EDR · VAS · Forensic

프로세스 실행·계정 사용·파일 변경·네트워크 연결과 보안 설정을 확인합니다. 마이터 어택 기반 탐지와 포렌식 흔적을 연결해 침해 판단의 근거를 확보합니다.

호스트 행위·상태 분석과 허용된 조치가 중심이며, 기기 인증·패치·접근권한은 운영 정책과 함께 설계합니다.

호스트 탐지 기능

03 / VISIBILITY & ANALYTICS

SIEM으로 연결하는 지속 검증

SIEM · AI · 로그 상관분석

웹·호스트·계정 로그를 시간·IP·자산·행위 맥락으로 연결합니다. 단일 경보를 넘어 공격 흐름과 관련 증거를 확인하고 조사·관제·정책 검토에 활용합니다.

SIEM은 가시성·분석 영역을 지원하는 핵심 기능이며, 대응 실행을 담당하는 SOAR와 역할을 구분합니다.

SIEM 분석 기능

04 / AUTOMATION & ORCHESTRATION

SOAR로 이어지는 정책 기반 대응

SOAR · 차단/격리 · 알림/이력

분석 결과를 사전에 정한 조건과 권한에 따라 차단·격리·알림으로 연결합니다. 승인 여부와 실행 결과, 후속 조치 이력을 확인해 대응을 운영으로 이어갑니다.

자동 대응과 승인 후 대응을 구분하며, 실행 가능한 조치는 제공 기능·구성·권한 범위에 따릅니다.

SOAR 대응 기능

CONTINUOUS VERIFICATION / CONNECTED DEFENSE

한 번의 인증 뒤에도,
행위와 위험을 계속 확인합니다.

접근이 허용된 이후의 활동도 보안 판단의 대상입니다.
확인한 증거를 다음 탐지와 대응 정책에 반영합니다.

01 / OBSERVE

행위를 관측

네트워크·웹·호스트에서
공격과 활동 로그를 확보합니다.

02 / ANALYZE

맥락을 분석

SIEM·AI로 로그를 연결해
관련 행위와 위험을 확인합니다.

03 / RESPOND

정책에 따라 대응

허용된 차단·격리·알림을
SOAR와 관제로 연결합니다.

04 / REVIEW

검증하고 개선

증거와 조치 결과를 검토해
탐지·운영 정책에 반영합니다.
