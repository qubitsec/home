# v7.1 공개 전 확인

현재 패키지는 전체 HTML 제작·검토본이며 운영에 자동 배포되지 않습니다.

## 1. 문안과 제공 범위

AI 기능의 현재 제공 범위, 정책 기반 자동 대응과 고객 승인 조치의 경계, 관제시간·사건 분류·통보·보고·지원 범위를 실제 상품·운영 정책과 대조합니다. 시스템의 상시 탐지와 전문인력의 관제시간을 구분합니다.

고객 로고·의견·제품 스크린샷의 공개 가능 여부와 인증·지정의 적용 제품·버전·유효 상태를 확인합니다. 상담 주소·전화·외부 양식·개인정보 처리방침·약관이 실제 사용하는 최신 연결인지 확인합니다.

## 2. 배포 대상

```text
사이트 루트/
  ko/                   이번 ZIP의 ko/ 전체
  res/v7.1/             이번 ZIP의 res/v7.1/ 전체
```

기존 운영 사이트 루트 `index.html`은 유지합니다. 언어 선택·지역 라우팅을 이번 로컬 시작 파일로 덮어쓰지 않습니다. 영문·일본어 경로를 덮어쓰지 않습니다.

`site-map.html`, `previews/`, `qa/`, `tools/`, 검토 문서, 원본 ZIP은 공개 디렉터리에 업로드하지 않습니다. 기존 v6·v7.0 리소스는 다른 언어·페이지가 사용 중인지 확인하기 전 삭제하지 않습니다.

## 3. 검색과 기존 주소

승인 후 29개 콘텐츠 페이지의 아래 검토용 설정을 운영 정책에 맞게 제거하거나 변경합니다.

```html
<meta name="robots" content="noindex, follow">
```

canonical·Open Graph URL을 최종 도메인과 대조하고 `sitemap-v7.1.xml`을 기존 사이트맵 운영 방식에 맞게 통합합니다. 로컬용 HTML 이동은 최종 운영에서 아래 HTTP 301 정책으로 정리할 수 있습니다.

```text
/ko/casestudy.html        → /ko/validation.html
/ko/pricing.html          → /ko/adoption.html
/ko/old-pricing.html      → /ko/adoption.html
/ko/platform_secureos.html → /ko/platform_edr.html
```

서버 유형이 확정되지 않았으므로 Nginx·Apache 설정 파일을 임의 적용하지 않았습니다.

## 4. 폰트·외부 리소스·캐시

현재 연결은 Google Fonts의 `Noto Sans KR`입니다. 조직 정책에 따라 기존 자체 호스팅 폰트 CSS로 교체할 수 있습니다. 교체 시 실제 굵기 300·400·500·600·700의 제공 여부와 한국어 줄바꿈을 확인합니다. 외부 요청을 허용할 경우 해당 요청에 대한 정책을 확인합니다.

개발자 도구의 Network와 Rendered Fonts에서 실제 폰트 로딩을 확인하세요. HTML의 `font-family` 문자열만으로 적용 성공을 판정하지 않습니다. CSS·JS의 `?v=7.1.0-20260914` 쿼리와 `res/v7.1/` 경로를 유지하고 필요 시 CDN 캐시를 갱신합니다.

현재 HTML의 inline 스타일과 SVG에 맞는 Content Security Policy가 필요합니다. 실제 서버 헤더·CSP·캐시 설정은 이번 정적 HTML 파일 작업에서 적용하지 않았습니다.

## 5. 사용자 환경 확인

실제 Windows Chrome·Edge, macOS Safari, Android·iOS 브라우저에서 메뉴·탭·긴 문구·표의 가로 스크롤·이미지 확대를 확인합니다. 100%/125% 배율 및 글자 확대 환경을 확인합니다. 외부 상담, 기본 이메일 앱, 클립보드, 파일 저장은 사용자 환경의 권한·정책 영향을 받습니다.

상담 양식은 초안 작성 기능입니다. 실제 자체 서버 접수가 필요하면 API·개인정보 고지·저장·오류 처리·메일/CRM 연동을 별도 구현해야 합니다. 현재 상태에서 ‘사이트에서 접수 완료’라고 문안을 바꾸지 않습니다.
