# PLURA-XDR + SOC — 관제 보고 구성 예시

문서 버전: 홈페이지 v7.0 / 2026-09-14

> **설명용 양식입니다.** 실제 고객 사건, 실제 탐지 결과, 조치 완료 기록 또는 계약상 제공 항목의 확정본이 아닙니다. 항목·주기·전달 방식은 서비스 범위에 따라 협의합니다.

## 1. 사건 요약

| 항목 | 기록할 내용 |
|---|---|
| 사건 식별 | 사건 번호, 최초 확인 시각, 분석 담당자 |
| 관측 내용 | 실제 수집한 로그에서 확인한 징후 |
| 대상 | 관련 자산·계정·서비스 |
| 현재 상태 | 조사 중 / 확인 완료 / 추가 확인 필요 등 실제 상태 |
| 판단 | 확인 사실과 의심 정황을 분리한 요약 |

## 2. 판단의 근거

| 증거 | 확인할 항목 |
|---|---|
| 웹 요청·응답 | 대상 URL·발생 시각·비식별 요청 및 응답·수집 범위 |
| 호스트 이벤트 | 대상 호스트·실행·변경·접근 흔적 |
| 포렌식 자료 | 확인한 아티팩트·수집 시각·변경 내용 |
| 연관 관계 | 시간·자산·계정 관계와 분석 근거 |
| 불확실성 | 수집하지 못한 로그, 추가 확인할 관계, 반대 근거 |

## 3. 영향 범위

확인된 영향, 영향이 의심되는 범위, 확인하지 못한 범위를 구분합니다. 요청 차단, 실제 실행 흔적, 침해 확정, 데이터 노출 및 유출 확정을 같은 의미로 취급하지 않습니다.

## 4. 대응과 승인 이력

| 시각 | 수행 내용 | 대상 | 권고·승인·실행 구분 | 승인·수행 주체 | 결과·추가 조치 |
|---|---|---|---|---|---|
| 실제 기록 입력 | 실제 수행 내용 입력 | 실제 대상 입력 | 해당 단계 입력 | 실제 담당자 입력 | 실제 결과 입력 |

## 5. 고객 통보와 후속 권고

최초 통보, 후속 설명과 공유 자료, 고객 확인·승인, 개선 권고, 재점검할 항목을 기록합니다. 최초 통보와 해결 완료는 서로 다른 시점입니다.

## 6. 사건 종료 또는 잔여 과제

종료 근거와 승인 주체, 미해결 사항, 고객 수행 과제, 추가 조사·복구 지원 여부와 범위를 구분합니다.
