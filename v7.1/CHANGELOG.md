# 변경 이력

## 7.1.0 — 2026-09-14

사용자가 선택한 **A안 Enterprise Blue**를 전체 사이트의 디자인 기준으로 확정했습니다.

- v7.0의 29개 콘텐츠 페이지를 공통 화이트·블루 디자인으로 재구성했습니다. 다크·민트 메인은 A안의 메인으로 교체했습니다.
- A안 메인의 주요 배치·통합 기능 카드·SOC 구성을 유지하고, 시안의 앵커 중심 상단 메뉴를 실제 페이지 하위 메뉴로 확장했습니다.
- 전체 메뉴·푸터·현재 위치·하위 페이지 내 탐색을 통일했습니다. 기존 URL 연결 4개를 유지했습니다.
- `Noto Sans KR` 우선 글꼴 체계, 외부 웹폰트 연결, 공통 제목·본문·자간 기준을 적용했습니다.
- 메인 위협 4개 탭의 상세 링크를 각각 올바른 페이지에 연결했습니다. 제로데이 탭은 `zero-day.html`로 이동합니다.
- 시안 표시와 컨셉 선택 팝업을 제거하고 푸터에 홈페이지 버전을 표시했습니다. 설명용 분석 화면의 예시 표시는 유지했습니다.
- 모바일 메뉴 포커스 처리, 메뉴 닫기와 화면 크기 변경 초기화, 탭의 방향키·Home·End 조작을 점검했습니다.
- 제품 스크린샷, 고객 자료, 자료실 필터·검색, FAQ, 상담 초안·복사·TXT 생성 기능을 이관했습니다.
- 일부 조사 오류를 바로잡고, 기능 상세의 PLURA-XDR 구성 기능 역할을 유지했습니다.
- 리소스를 `res/v7.1/`로 분리하고 CSS·JavaScript에 빌드 쿼리를 추가했습니다.
- 전체 페이지 목록, 배포 전 확인 문서, 검증 결과 및 화면 미리보기를 포함했습니다.

v7.0 ZIP과 기존 A·B·C 시안 파일은 변경하지 않았습니다. 운영 홈페이지·제품 콘솔·외부 상담 양식에 대한 배포나 변경은 수행하지 않았습니다.
