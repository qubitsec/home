## 검증 방식과 한계

브라우저 localhost 접근을 시도했으나 `ERR_BLOCKED_BY_ADMINISTRATOR`가 발생했습니다. 화면 검사는 오프라인 Chromium `set_content`에서 로컬 리소스를 임시 인라인하고 외부 요청을 차단하여 수행했습니다. 임시 변환은 검토 문서에만 적용했고 배포 HTML에는 반영하지 않았습니다. 설치된 한국어 대체 글꼴을 사용했습니다.

동작 테스트는 PC 포인터/키보드와 모바일 폭의 메뉴를 대상으로 했습니다. 이번 동작 테스트는 모션 감소 모드로 수행했으므로 전환 애니메이션의 모든 프레임을 검증했다는 의미가 아닙니다. 관련 CSS와 스크립트는 입력 파일 그대로입니다.

HTTP 검사에는 Python 로컬 HTTP 클라이언트를 사용했습니다. 브라우저 HTTP 통합시험, 운영 서버 배포, 모든 외부 URL 접속, 전 브라우저 호환성 인증은 수행하지 않았습니다.
