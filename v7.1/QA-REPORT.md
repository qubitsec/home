## 방법과 제한

오프라인 Chromium `set_content`에 로컬 CSS·JS·이미지를 임시 인라인하여 렌더링했습니다. 배포 HTML에는 인라인 리소스를 삽입하지 않았습니다. 정상 제품 코드와 동일한 DOM·CSS·JavaScript를 사용하되, 원래 외부 script는 검토 문서 끝에서 실행했습니다.

Chromium의 localhost 탐색은 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되어 브라우저 HTTP 통합시험은 수행하지 못했습니다. 상대 경로는 정적 참조 검사와 별도 Python HTTP GET으로 검증했습니다. 웹폰트는 외부 요청을 차단한 상태의 설치된 Noto Sans CJK KR 등 한국어 글꼴로 렌더링했으므로 실제 사용자 브라우저와 글리프·줄바꿈이 조금 다를 수 있습니다.

호버 검사는 PC 포인터 환경에서, 모바일 선택은 390px 화면 및 touch 지원 환경에서 확인했습니다. 실제 운영망 접속, 서버 변경, 배포, 외부 문서·영상·로그인 요청, 외부 서비스 가입·제출은 하지 않았습니다. 전체 웹 접근성 인증이나 모든 브라우저 호환성 판정을 의미하지 않습니다.
