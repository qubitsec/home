MITRE ATT&CK-BASED DETECTION

마이터 어택 기반 탐지,
공격자의 행위를 읽습니다.

PLURA-EDR은 서버·PC의 프로세스·파일·계정 행위를 탐지하고 마이터 어택(MITRE ATT&CK)의 전술·기법과 연결합니다. PLURA-XDR은 웹 로그와 AI·포렌식 분석을 더해 공격의 시작부터 후속 행위까지 추적합니다.

통합 도입 상담

MITRE ATT&CK

행위 탐지 → 기법 분류
→ AI·포렌식 분석

단순한 기법 목록이 아니라, 어떤 행위가 탐지됐고 어떤 증거가 남았는지 확인하는 기술입니다.

EDRATT&CKAI · FORENSIC
탐지 기술대표 공격 기법웹셸 탐지기술 자료

BEHAVIOR → TECHNIQUE → EVIDENCE

탐지된 행위를,
공격 전술·기법과 연결합니다.

탐지는 PLURA의 필터·행위 분석이 수행하고, ATT&CK은 탐지된 행위를 해석하는 기준이 됩니다. 매트릭스에서 원문 로그와 연관 증거까지 이어집니다.

01 / DETECT

EDR 행위 탐지

감사 로그와 시스템 이벤트에서 프로세스 실행, 파일 변경, 계정 사용과 외부 연결을 분석합니다. 수집된 행위가 탐지의 출발점입니다.

EDR 행위 탐지 보기

02 / MAP

ATT&CK 기법 분류

탐지 필터와 연결된 기법 ID(TID), 전술, 관련 로그를 함께 확인합니다. 개별 경보가 공격 흐름에서 갖는 의미를 파악합니다.

03 / ANALYZE

AI·포렌식 분석

탐지 이벤트의 의도와 연관 기법을 AI로 분석하고, 연결된 포렌식 자료로 실행 흔적과 영향을 확인합니다.

AI 분석·대응 보기

TECHNIQUE IDS / INVESTIGATION EXAMPLES

T1505.003 ↗ (새 탭)
Web Shell · 웹셸		웹셸 설치·접근과 웹 서버를 통한 명령 실행 정황웹 경로의 파일 생성·변경, 웹 프로세스의 자식 프로세스, 후속 명령
T1110.004 ↗ (새 탭)
Credential Stuffing		유출된 계정 조합을 재사용하는 자동화 로그인 시도계정·IP, 요청 본문, 인증 결과, 반복 시도와 세션 행위

대표 기법과 조사 관점을 설명한 예시입니다. 실제 탐지 범위는 적용 필터·감사 정책·수집 데이터에 따라 달라지며, 모든 이벤트에 세 기법이 자동으로 부여된다는 의미는 아닙니다.

WEB SHELL / T1505.003

웹셸은 업로드 경보를 넘어,
서버에서 실행된 행위까지 탐지합니다.

PLURA-WAF의 웹 공격 정보와 PLURA-EDR의 호스트 행위 탐지를 연결합니다. 웹 요청이 있었는지와 서버에서 실제로 무엇이 실행됐는지를 함께 판단합니다.

01

웹 요청과 파일 흔적 확인

의심 요청의 URL·본문과 서버 내 파일 생성·변경 흔적을 함께 살펴봅니다.

02

EDR의 행위 기반 탐지

웹 서버 프로세스가 생성한 자식 프로세스, 명령 실행, 파일 접근과 외부 연결을 분석합니다.

03

ATT&CK 기법과 증거 연결

웹셸 관련 행위를 T1505.003 관점으로 해석하고 관련 실행 기법·원문·포렌식 흔적을 함께 검토합니다.

04

AI 분석과 정책 기반 대응

AI가 공격 맥락 분석을 지원하고, 허용된 정책에 따라 차단·격리와 증거 보존을 수행합니다.
