공식 기법 설명 ↗새 탭

확인할 행위

웹 서버에 웹셸을 두어 원격 명령 실행과 지속적인 접근에 사용하는 행위입니다.

연결할 증거 예시

웹 경로의 파일 생성·변경, 웹 요청, 웹 프로세스의 자식 프로세스

해석 시 확인 사항

업로드 흔적과 실행 흔적을 연결하고, 웹셸 의심 파일만으로 침해 범위를 확정하지 않습니다.

공식 전술 분류에 대표 기법을 배치한 설명용 매트릭스입니다. 제품의 전체 탐지 범위나 실제 탐지 결과를 나타내지 않습니다. 하나의 기법은 여러 전술에 연결될 수 있으며, 전술의 배열은 고정된 공격 순서를 뜻하지 않습니다.

탐지된 행위를,

탐지는 PLURA의 필터·행위 분석이 수행하고, ATT&CK은 탐지된 행위를 해석하는 기준이 됩니다. 매트릭스에서 원문 로그와 연관 증거까지 이어집니다.

01 / DETECT

EDR 행위 탐지

감사 로그와 시스템 이벤트에서 프로세스 실행, 파일 변경, 계정 사용과 외부 연결을 분석합니다. 수집된 행위가 탐지의 출발점입니다.

EDR 행위 탐지 보기

02 / MAP

ATT&CK 기법 분류

탐지 필터와 연결된 기법 ID(TID), 전술, 관련 로그를 함께 확인합니다. 개별 경보가 공격 흐름에서 갖는 의미를 파악합니다.

03 / ANALYZE

AI·포렌식 분석

탐지 이벤트의 의도와 연관 기법을 AI로 분석하고, 연결된 포렌식 자료로 실행 흔적과 영향을 확인합니다.

PLURA-WAF의 웹 공격 정보와 PLURA-EDR의 호스트 행위 탐지를 연결합니다. 웹 요청이 있었는지와 서버에서 실제로 무엇이 실행됐는지를 함께 판단합니다.

01

웹 요청과 파일 흔적 확인

의심 요청의 URL·본문과 서버 내 파일 생성·변경 흔적을 함께 살펴봅니다.

02

EDR의 행위 기반 탐지

웹 서버 프로세스가 생성한 자식 프로세스, 명령 실행, 파일 접근과 외부 연결을 분석합니다.

03

ATT&CK 기법과 증거 연결

웹셸 관련 행위를 T1505.003 관점으로 해석하고 관련 실행 기법·원문·포렌식 흔적을 함께 검토합니다.

04

AI 분석과 정책 기반 대응

AI가 공격 맥락 분석을 지원하고, 허용된 정책에 따라 차단·격리와 증거 보존을 수행합니다.
