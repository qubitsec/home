NIST ZERO TRUST / PRINCIPLES AND ROLES

NIST 제로트러스트 원칙에서,
PLURA-XDR의 역할을 확인하세요.

NIST SP 800-207의 기본 원칙을 기준으로,
보안 상태 확인·행위 분석·정책 개선의 역할을 설명합니다.

  • 01연계 설계

    데이터·서비스를 자원으로

    RESOURCES

    모든 데이터 소스와 컴퓨팅 서비스를 보호 대상 자원으로 봅니다.

  • 02연계 설계

    위치와 무관한 통신 보호

    SECURE COMMUNICATION

    네트워크 위치에 관계없이 모든 통신을 보호합니다.

  • 03연계 설계

    세션별 최소 권한 접근

    PER-SESSION ACCESS

    개별 자원에 대한 접근을 세션별로 평가하고 필요한 최소 권한만 허용합니다.

  • 04판단 근거

    동적 정책 기반 접근

    DYNAMIC POLICY

    사용자·앱·기기의 상태와 행위·환경 정보를 반영해 접근을 결정합니다.

  • 05상태 확인

    자산 무결성·상태 확인

    ASSET SECURITY POSTURE

    보유·연관 자산의 무결성과 보안 상태를 지속적으로 확인합니다.

  • 06연계 설계

    접근 전 인증·인가

    AUTHENTICATION & AUTHORIZATION

    접근 전 인증·인가를 엄격히 적용하고, 통신 중에도 정책에 따라 재평가합니다.

  • 07분석·개선

    정보 수집·분석·개선

    CONTINUOUS IMPROVEMENT

    자산·네트워크·통신 정보를 수집·분석해 보안 상태와 정책을 개선합니다.

위 항목은 NIST SP 800-207 §2.1의 기본 원칙 요약입니다. 강조 항목은 PLURA-XDR의 상태 확인·분석과 연결되는 역할이며, 전체 원칙의 충족이나 인증을 의미하지 않습니다. 연계 설계에 해당하는 인증·인가·접근제어는 조직의 아키텍처와 실제 연동 범위에 따라 별도로 설계합니다.

NIST 제로트러스트 원칙 공식 원문 (새 탭)

PLURA-XDR / FOUR CONNECTED ROLES

가시성을 만들고,
분석을 대응으로 연결합니다.

아래 4개 항목은 PLURA-XDR의 지원 기능을 정리한 것으로,
NIST의 공식 분류나 충족 비율을 의미하지 않습니다.

01 / NETWORK & ENVIRONMENT

네트워크·환경의 가시성

WAF · 네트워크/보안 장비 로그

웹 요청·응답의 헤더·본문과 지원 장비·호스트의 연결 로그를 수집·분석합니다. 공격 요청과 접근 흐름을 연결하고 정책에 따른 웹 공격 차단에 활용합니다.

수집·분석과 웹 방어 범위의 지원이며, 전사 네트워크 세분화나 모든 통신의 제어를 자동 대체하지 않습니다.

웹 보호 기능

02 / DEVICE

서버·PC 행위와 보안 상태

EDR · VAS · Forensic

프로세스 실행·계정 사용·파일 변경·네트워크 연결과 보안 설정을 확인합니다. 마이터 어택 기반 탐지와 포렌식 흔적을 연결해 침해 판단의 근거를 확보합니다.

호스트 행위·상태 분석과 허용된 조치가 중심이며, 기기 인증·패치·접근권한은 운영 정책과 함께 설계합니다.

호스트 탐지 기능

03 / VISIBILITY & ANALYTICS

SIEM으로 연결하는 지속 검증

SIEM · AI · 로그 상관분석

웹·호스트·계정 로그를 시간·IP·자산·행위 맥락으로 연결합니다. 단일 경보를 넘어 공격 흐름과 관련 증거를 확인하고 조사·관제·정책 검토에 활용합니다.

SIEM은 가시성·분석 영역을 지원하는 핵심 기능이며, 대응 실행을 담당하는 SOAR와 역할을 구분합니다.

SIEM 분석 기능

04 / AUTOMATION & ORCHESTRATION

SOAR로 이어지는 정책 기반 대응

SOAR · 차단/격리 · 알림/이력

분석 결과를 사전에 정한 조건과 권한에 따라 차단·격리·알림으로 연결합니다. 승인 여부와 실행 결과, 후속 조치 이력을 확인해 대응을 운영으로 이어갑니다.

자동 대응과 승인 후 대응을 구분하며, 실행 가능한 조치는 제공 기능·구성·권한 범위에 따릅니다.

SOAR 대응 기능

CONTINUOUS VERIFICATION / CONNECTED DEFENSE
