## 점검 방식과 한계

이 환경의 Chromium은 로컬 HTTP/file 탐색을 관리자 정책으로 차단합니다. 해당 정책은 변경하지 않았습니다. 대신 실제 HTML을 Chromium 문서에 주입하되, 렌더링용 복사본에만 동일한 CSS·JavaScript·로컬 이미지 내용을 인라인화했습니다. 사이트 원본의 정적 리소스 구조는 그대로 유지했습니다.

따라서 이 보고서는 **콘텐츠·화면·문서 내 UI·정적 링크 점검 결과**입니다. 실제 서버 HTTP 응답이나 페이지 이동을 통한 통합시험의 통과를 의미하지 않습니다. 링크는 실제 파일 존재와 앵커·메뉴 href를 대조했습니다. 운영 배포와 사용자 브라우저의 최종 확인은 별도입니다.
